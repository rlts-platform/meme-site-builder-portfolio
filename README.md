# Meme Site Builder (MSB)

**An AI-powered website builder for meme coin projects.**

## What is Meme Site Builder?

Meme Site Builder is a web application designed to help crypto and meme coin creators build a website for their token without having to design and code everything themselves.

Instead of starting from a blank page, users can describe their project's style, provide token details and visual assets, and work through a conversational building process to create a website concept tailored to their project.

## Core Features

- **Conversational site creation:** Guide users through building a token website using a chat-based workflow.
- **Multiple design variations:** Generate and compare different visual directions, including dark, vibrant, retro, and cyberpunk-inspired styles.
- **Token information:** Collect project details such as token name, ticker, contract address, supply, social accounts, and project story.
- **Image and asset support:** Incorporate user-provided images and other visual assets into the site-building process.
- **Live preview and editing:** Preview generated designs and refine the result through conversational instructions.
- **Site dashboard:** Organize projects and track their statuses, with options to edit, view, and copy published site addresses when available.
- **Pricing and subscription structure:** Define tiers intended for individual creators, growing projects, and teams, with different site limits and capabilities.

## Technology Stack

- **React** — component-based user interface
- **Vite** — development server and production build tooling
- **JavaScript** — application logic
- **Tailwind CSS** — styling and responsive layouts
- **Base44 SDK** — application backend and data integration
- **React Router** — client-side navigation
- **TanStack Query** — data fetching and caching
- **Framer Motion** — interface animations
- **Solana payment concepts** — intended payment options for crypto-focused users

## Project Goal

The goal of Meme Site Builder is to simplify the process of launching a professional-looking website for a meme coin project. By combining guided input, AI-assisted generation, design choices, and a project dashboard, the platform aims to make website creation more accessible to creators without requiring a traditional web development workflow.
